		\block{Introduction}{
			\begin{itemize}
				\item The speed of RNA polymerase II (Pol II) elongation, measured as the number of nucleotides synthesized per unit of time, plays an important role in RNA metabolism. Changes in Pol II speed can affect several co-transcriptional processes
				\parencite{munizRNAPolymeraseII2021}.
				
					\item A recent study by  \textcite{debesAgeingassociatedChangesTranscriptional2023} showed that organism aging is associated with an increase in Pol II speed, whereas lifespan-prolonging interventions tend to decrease it. 
					
					\item We present a novel computational method that jointly estimates changes in Pol II elongation speed and intron splicing speed using total RNA-seq data.
		
		
			
		\end{itemize}
		}
		
		\block{Method}{
		\begin{itemize}
				\item  Our method works with total RNA-seq, which is a mixture of nascent and mature RNA. Changes in gene expression affect both the nascent and mature components, while changes in Pol II speed and splicing time affect the nascent RNA only.					
				
		\end{itemize}
		
		\begin{center}
			\includegraphics[width=0.47\linewidth]{figures/total_rna_with_bg.png}\\[1ex]
			\small\textbf{Figure 1.} Total RNA-seq.
		\end{center}
		
		
		
		
		
		\begin{itemize}
			\item As introns are predominantly present in the nascent RNA (with the exception of intron retention), changes in the intron coverage can be linked to the changes in Pol II speed and splicing time.	
			
		\end{itemize}
		
		\begin{center}
			\includegraphics[width=0.81\linewidth]{figures/pol_ii_speed_figure.png}\\[1ex]
			\small \textbf{Figure 2.}  Effect of the change in Pol II speed. In the condition with a faster polymerase (left), there are fewer polymerases currently transcribing a gene, compared to the condition with a slower polymerase (right). Note that the amount of mature RNA is not affected by the change in elongation speed.
		\end{center}
		
		\begin{itemize}
			\item Intronic reads come from introns that are either still being transcribed or from introns that are fully finished (but not spliced and degraded yet). These two types of introns have different coverage patterns, as transcribing introns will produce reads only in the region that was already transcribed.
			
		\end{itemize}

\vspace{1mm}

\begin{itemize}
	\item We used the principles above to derive our model (see our bioRxiv preprint for details). The model consists of:
	\begin{itemize}
		\item Vector of explanatory variables $\mathbf{x}$ and logarithm of library size $\ell$, describing each sample.
		\item Parameter vectors $\boldsymbol{\alpha}$, $\boldsymbol{\beta}$, and $\boldsymbol{\gamma}$, describing log fold-changes (LFC) effects of $\mathbf{x}$ on gene expression, Pol II speed, and intron splicing time, respectively.
		\item Intercept parameters $c_{\text{exon}}$, $c_{\text{intron}}$ and $\theta$.
	\end{itemize}
	\item The model predicts, for every gene, the expected exon read count $\mu$, and for every intron, the intron read count $\nu$ and the fraction of intronic reads originating from currently transcribing introns $\pi$: 
	$$
	\mu =  \exp \left( c_{\text{exon}} + \ell +\mathbf{x}^\mathsf{T} \boldsymbol{\alpha} \right)
	$$ 
	$$
	\nu = \exp \left(c_{\text{intron}}+ \ell + \theta + \mathbf{x}^\mathsf{T} \left( \boldsymbol{\alpha} - \boldsymbol{\beta} \right) \right) + \exp \left( c_{\text{intron}} + \ell + \mathbf{x}^\mathsf{T} \left( \boldsymbol{\alpha} + \boldsymbol{\gamma} \right) \right)
	$$		
	$$
	\pi = \sigma \left( \theta -\mathbf{x}^\mathsf{T} \left( \boldsymbol{\beta} + \boldsymbol{\gamma} \right) \right)
	$$
	\item The model is fitted by maximum likelihood estimation using exon and intron read counts together with intron coverage (read positions within introns). Parameter significance is assessed with a likelihood ratio test.
	
\end{itemize}


	
		
		
		
}

			\block{Results}{\begin{itemize}
				\item We used a publicly available mouse dataset from \textcite{demajoGenomicInstabilityNaturally2021a} to compare myocardium samples of young (12 weeks) wild-type mice with four groups: old (104 weeks) wild-type mice, mice with myocardium-specific knockout of the \textit{Ercc1} gene, a mouse model of Hutchinson–Gilford Progeria Syndrome (HGPS), and \textit{Tert}-deficient mice with reduced telomere length.
				
					
			\end{itemize}
